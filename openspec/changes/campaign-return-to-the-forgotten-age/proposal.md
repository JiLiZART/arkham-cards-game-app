## Why

Return to The Forgotten Age replays the 10 scenarios with the box's setup cards, 4 replacement encounter sets, the Return to the Rainforest additions and new acts, locations and enemies: 317 cards used, 31 working, no real tokens, no script, and the generated folder lacks Return to The Depths of Yoth altogether (report `tfa.md`, sections 1 and 4.13). Its generated setups copy the base setups' errors and add their own: both Entryways in play in Return to The Doom of Eztli, one act deck of four in Return to Threads of Fate, only act 53054 in Return to The City of Archives, no "one of two locations per symbol" exploration decks. Once `campaign-the-forgotten-age` lands, each Return scenario is its base scenario's script and token table plus the box's differences.

## What Changes

- **The campaign becomes hand-written**: `content/campaigns-generated/return-to-the-forgotten-age/` moves to `content/campaigns/return-to-the-forgotten-age/` (`generated: false`), with `scripts/return-to-<scenario>.ts` per scenario composing the base scenario's script, and Return to The Depths of Yoth added (generated by `scenario-import-fixes` first, then hand-fixed).
- **Every Return scenario plays as its setup card says** (53016, 53017, 53028, 53038, 53045, 53048, 53053, 53059, 53061, 53066): the base setup, then the Return-to steps (exploration decks of one location per connection symbol out of two, the original Burial Pit, Underground Ruins and Secret Passage removed and the five Eztli locations and the Harbinger replaced by their new versions, three Pit Vipers set aside, a fourth act deck g/h in Threads of Fate with Veda Whitsley set aside, one of each Present-Day pair at random in The Boundary Beyond with an exploration deck of the twelve Ancient locations only, "A Familiar Pattern" in place of act 1a, the Southern Corridors with the Cyclopean Vaults and Alien Conservatory set aside until act 1b and act 2a replaced by 53054, Perils of Yoth shuffled into every new exploration deck, an exploration deck of four Otherworld locations with the new Shattered locations set aside), the Return-to rule "after a successful exploration ends, shuffle the top card of the encounter deck into the exploration deck" in every explored scenario, and the camp's and the Mouth's supply checks usable anywhere.
- **Each Return scenario's token table is its base scenario's**, the reference card being the base card and the setup card a second scenario card with no token lines, as `scenario-import-fixes` establishes (`setupCards`, ADR-0038).
- **Every rttfa encounter card works**: the 67 cards of the Return-to sets (the 4 replacement sets Cult of Pnakotus, Doomed Expedition, Temporal Hunters, Venomous Hate; Return to the Rainforest; the 10 scenario sets), in `content/packs/return/cards.json` or `content/packs/return/scripts/<code>.ts`, including Veda Whitsley 53037 and the Key of Eztli supply (53020).
- **Flow**: the base campaign's hand-fixed `flow.json` with the Return-to log keys as `scenario-import-fixes` writes them, the Resupply Point's unlimited trauma healing and experience converted to supply points (up to 10, at 2 per point) through `buySupplies.xpRate`, the Key of Eztli recorded in a supply list from the Depths' resolution, the "sticky goop" record, and Return to Threads of Fate's act-card experience that may only buy supplies or healing.
- **The base campaign can use the replacement sets.** Starting The Forgotten Age offers the option to use the box's 4 replacement encounter sets (Cult of Pnakotus for Dark Cult, Doomed Expedition for Expedition, Temporal Hunters for Temporal Flux, Venomous Hate for Yig's Venom) and the Return to the Rainforest addition, through `CampaignDef.options` with `replaceSets` and `addSets` as `scenario-import-fixes` defines it. The bookmark's "shuffle old and new together" variant is not offered.
- Coverage: `return-to-the-forgotten-age` and its 10 scenarios complete; `docs/campaign-program.md` rttfa row at 0 encounter cards left.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `campaign-play`: Return to The Forgotten Age playable to every resolution, each scenario the base plus the box's setup; the base campaign offers the replacement-sets option at creation.
- `card-content`: every rttfa encounter card declared; the vocabulary it adds (one location of two per symbol, a per-symbol random pick that removes the rest, explore reactions on investigate, fight and evade, an evade whose cost is a supply, a treachery attached to a location worth vengeance, doom divided evenly, copies drawn from the victory display).

## Decided (assumed)

- A Return scenario's script composes the base's through `compose()` (setup after the base's, objectives before); it never copies the base. The scenario file names the base card as `card` and the setup card in `setupCards`.
- The replacement sets are always in Return to The Forgotten Age; Return to the Rainforest is always added to the Rainforest set there (the bookmark says "added", not "replaces").
- Return-to symbols: the new Jungle, Eztli, Present-Day, K'n-yan, Yoth and Shattered locations carry `symbol`/`connectsTo` from their scans in `content/packs/return/cards.json`; the base locations already have theirs, so "one of two per symbol" is a `bySymbol` pick over both sets.
- Return to The Depths of Yoth is set up as the base plus the Return-to Harbinger and Perils of Yoth 53060 shuffled into each new exploration deck; its generated file comes from `scenario-import-fixes` and is hand-fixed here like the others.

## Decided (user)

- **The base campaign offers the replacement sets as a single option**, chosen at creation, off by default, through `CampaignDef.options` with `replaceSets` and `addSets` (`scenario-import-fixes`), not redefined here. The bookmark (`inspired/AHC_CYOA-main/Return To Bookmarks/Return To Bookmarks - For Reading.pdf`) lists the swaps:

  | Replacement set   | Replaces      |
  | ----------------- | ------------- |
  | Cult of Pnakotus  | Dark Cult     |
  | Doomed Expedition | Expedition    |
  | Temporal Hunters  | Temporal Flux |
  | Venomous Hate     | Yig's Venom   |

  The bookmark's variant of shuffling the old and new sets together is rejected and not offered.

- **Return to the Rainforest (53067–53070) is in the option.** It is an addition to the Rainforest set, not a replacement, so the option lists it under `addSets` beside the four `replaceSets` pairs; `scenario-import-fixes` gives the option both lists.
